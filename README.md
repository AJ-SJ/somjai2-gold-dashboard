# Somjai2 Gold Shop Website

ระบบช่วยงานหน้าร้านทองภาษาไทยสำหรับพนักงาน สร้างด้วย Streamlit โดยเน้นอ่านราคาและคำนวณงานหน้าร้านได้รวดเร็ว ไม่มีระบบพยากรณ์ราคา

## ฟังก์ชันในเว็บไซต์

- ราคาประกาศสมาคมค้าทองคำสำหรับทองคำแท่งและทองรูปพรรณ 96.5%
- ราคาซื้อ ขาย เวลาและครั้งที่ประกาศ รวมถึงการเปลี่ยนแปลงจากวันก่อน
- การ์ดราคาตามน้ำหนัก 6 สลึง 1 บาท 2 สลึง 1 สลึง ครึ่งสลึง และ 1 กรัม
- ช่องกรอกน้ำหนักกำหนดเองได้ทั้งหน่วยกรัมและบาททองคำ
- เครื่องคำนวณซื้อและขาย พร้อมค่ากำเหน็จตัวอย่าง
- เครื่องประเมินวงเงินจำนำเบื้องต้น
- ส่วนแนะนำสินค้า บริการ คำถามที่พบบ่อย และแบบฟอร์มติดต่อ
- Responsive design สำหรับจอคอมพิวเตอร์และโทรศัพท์
- เลือกรอบตรวจราคาสมาคมอัตโนมัติได้ทุก 15 วินาที 30 วินาที 1 นาที หรือ 5 นาที
- แสดงเวลาประกาศของสมาคมและเวลาที่หน้าเว็บตรวจข้อมูลล่าสุดแยกกัน
- แจ้งเตือนบนหน้าจอเมื่อราคาหรือครั้งที่ประกาศเปลี่ยน

## ตั้งค่าข้อมูลร้าน

แก้ค่าด้านบนของ `app.py` ได้แก่ `SHOP_NAME`, `SHOP_TAGLINE`, `SHOP_PHONE`, `SHOP_LINE`, `SHOP_ADDRESS` และ `SHOP_HOURS` ก่อนเผยแพร่จริง

การตรวจราคาอัตโนมัติเป็นการ polling ตามรอบที่เลือก หน้าเว็บต้องเปิดอยู่และเซิร์ฟเวอร์ต้องทำงาน ระบบไม่สามารถรับ push จากสมาคมได้โดยตรง หาก API สมาคมล่าช้าหรือใช้งานไม่ได้ หน้าจอจะแจ้งข้อผิดพลาดและไม่สร้างราคาแทน นโยบายรับจำนำ การเก็บข้อมูลลูกค้า และเอกสารยืนยันตัวตนต้องปรับตามใบอนุญาตและข้อกำหนดของร้าน

## เปิดใช้งานบน Mac

วิธีง่ายที่สุด เปิด Terminal ในโฟลเดอร์ แล้วรัน:

```bash
chmod +x run_app.command
./run_app.command
```

ไฟล์นี้จะสร้างหรือใช้ `.venv` เดิม ติดตั้งแพ็กเกจที่ยังขาด แล้วเปิดเว็บไซต์ให้

หรือรันทีละคำสั่ง:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

ถ้าเห็น `ModuleNotFoundError: No module named 'streamlit_autorefresh'` แปลว่ายังไม่ได้ติดตั้ง requirements เวอร์ชันล่าสุด ให้หยุดเว็บด้วย `Control + C` แล้วรัน `pip install -r requirements.txt` ก่อนเปิดใหม่ ตัวเว็บเวอร์ชันนี้จะไม่ล่มหากแพ็กเกจดังกล่าวยังไม่มี แต่จะใช้ได้เฉพาะปุ่มตรวจราคาด้วยตนเองจนกว่าจะติดตั้งสำเร็จ
